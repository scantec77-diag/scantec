# Scantec — Diagnóstico Automotor

Prototipo web para celular.

## Incluye
- Saludo según el horario.
- Dictado de voz (si el navegador lo permite).
- Búsqueda web de códigos de falla y síntomas.
- Historial de consultas guardado en el navegador.
- Botón que copia la consulta y abre ChatGPT por separado.

## Publicar con GitHub Pages
1. En GitHub, abrir el repositorio **scantec77-diag/scantec**.
2. Entrar a **Settings (Configuración)** > **Pages (Páginas)**.
3. En **Build and deployment (Compilación e implementación)** elegir **Deploy from a branch**.
4. Elegir **main** y **/(root)**, luego **Save (Guardar)**.
5. Después de que GitHub publique el sitio, ingresar en https://scantec77-diag.github.io/scantec/

## Limitaciones de esta primera versión
- El monograma de la cabecera es provisorio; todavía no incluye el logo original.
- ChatGPT se abre en otra pestaña; no está incorporado dentro del sitio.
- Los diagnósticos se guardan solo en el navegador, no se sincronizan.
- Requiere internet para buscar información y para abrir ChatGPT.
