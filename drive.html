Ayuda para conectar Google Drive

¿Dónde consigo el ID de cliente?

  1. Entrá a Google Cloud Console → Google Auth Platform → Clientes ↗ y seleccioná el proyecto de Scantec.
  2. Activá la Google Drive API para el mismo proyecto.
  3. En Público (Audience), seleccioná Externo · En pruebas y agregá tu cuenta a Usuarios de prueba. Completá el nombre y correo en Branding.
  4. En Acceso a datos agregá https://www.googleapis.com/auth/drive.metadata.readonly. Google lo considera un permiso restringido; para publicarlo a todos los usuarios puede exigir verificación. Para una prueba personal, dejá la aplicación en modo Testing.
  5. Creá un cliente OAuth de tipo Aplicación web. En Orígenes de JavaScript autorizados escribí exactamente https://scantec77-diag.github.io, sin agregar /scantec.
  6. Copiá el ID de cliente y pegalo arriba. No uses ni compartas secretos de cliente.
  7. Pulsá Conectar Drive con Google, elegí la cuenta propietaria de la carpeta ScanTec 77 y aceptá el permiso.

Scantec recorre la carpeta cuando conectás o pulsás «Actualizar biblioteca». Esta primera etapa no realiza copias automáticas en segundo plano, ni sincroniza los clientes de Mi Taller. Eso continúa funcionando mediante Firebase y lo ampliaremos por separado.
